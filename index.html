Get started

Up and running in under a minute — no installer required.

  1. Download and unzip. Extract Navuryx-Emulations-Portable-v1.0.0.zip anywhere on your Windows 10/11 PC.
  2. Open Navuryx Emulations.exe. If Windows SmartScreen appears, click More info, then Run anyway.
  3. Add your games or ISOs. Pick any console in Games, switch to Console Mode, or create a Virtual Machine in the VMs / Devices tabs.
  4. Play. Plug in any Xbox, PlayStation, or Switch Pro controller, or customize keyboard controls in Settings.

Questions

 

Is it free?

Yes. Navuryx Emulations is free for Windows, and includes the WebAssembly browser player and Game Dump Helper.

Where do I get BIOS, keys, or games?

Only use games, ROMs, BIOS dumps, keys, firmware (.ipsw), and OS images from hardware you own or that are freely shared by their creators. None are bundled.

How do Xbox One / Series X|S and PS5 Native vs Emulator modes work?

Both Windows desktop editions have experimental launch support for decrypted PS5 ELF/OELF executables and Xbox One / Series X|S game folders. Emulator mode uses the built-in x86-64 CPU core. Native mode runs directly on a Windows x64 host. Commercial game compatibility depends on the graphics and system services each title needs.

Windows SmartScreen says the app is unrecognized

Self-signed builds show this warning until signed with an EV certificate. Click More info and then Run anyway.
